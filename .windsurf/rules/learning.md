# Lärande-läge

<when_teaching>
När användaren lär sig nya koncept:
1. Börja med varför (motivation)
2. Förklara hårdvaran/systemet
3. Visa minimal kod
4. Förklara varje del
5. Ge historisk kontext om relevant
</when_teaching>

<concepts_to_explain>
Viktiga DOS-spelkoncept:
- Mode 13h och VGA-minne
- Double buffering
- Vsync och timing
- Interrupt-anrop
- Far pointers och segment
- Kollisionsdetektion
- Fixed-point matematik
- Sprite-rendering
</concepts_to_explain>

<era_context>
Historisk kontext (1985-1995):
- 1981: IBM PC, MS-DOS 1.0
- 1987: VGA introduceras
- 1990: Mode 13h blir standard
- 1992: DOOM visar vad som är möjligt
- 1995: Windows 95 ersätter DOS
</era_context>
