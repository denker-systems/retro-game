SOUND FILES FOR RETRO DOS PLATFORMER
=====================================

Place WAV files here for Sound Blaster playback.

REQUIRED FILES:
- JUMP.WAV    - Jump sound effect
- MENU.WAV    - Menu navigation beep
- SELECT.WAV  - Menu selection confirm
- LAND.WAV    - Landing sound

WAV FORMAT REQUIREMENTS:
- 8-bit unsigned PCM (not 16-bit)
- Mono (not stereo)
- Sample rate: 11025 or 22050 Hz
- Max size: ~60KB per file

If files are missing, PC Speaker fallback is used.

CREATING WAV FILES:
1. Use Audacity or similar
2. Set: Mono, 8-bit, 11025 Hz
3. Export as "Other uncompressed files"
4. Choose "WAV (Microsoft)" and "Unsigned 8-bit PCM"

DOS FILENAME RULES:
- Max 8 characters + 3 extension (8.3 format)
- UPPERCASE recommended
- No spaces or special characters
